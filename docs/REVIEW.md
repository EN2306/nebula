# PS1 review and improvement plan

This is the pre-improvement review. See [implemented improvements and measured results](IMPROVEMENTS.md) for the current state; the baseline and findings below are retained for comparison.

## Assessment

The current project already delivers a useful PS1 prototype: eight-file import, weekly A/B/C scheduling, full-workload checks, network geometry, scenario comparison, CSV export, saved plans, authenticated planner accounts and optional contextual chat. The strongest next investment is demonstrable correctness and hidden-instance quality, followed by a working judging deployment. More generic chatbot features have lower value than those gaps.

This assessment is based on the current source/tests and the [pinned official brief](../problem-statement/PS1/PS1_README.md), particularly sections 2.4–2.7, 3.2 and 4. The organisers provide no numeric rubric weights here.

## Recommended implementation order

1. Fix stale-output and validation gaps; add adversarial fixtures and a reproducible benchmark.
2. Establish official rule alignment and prepare a hosted judging deployment.
3. Improve search against that benchmark, keeping the current solver as a baseline.
4. Add evidence-backed delay explanations and one convincing disruption demonstration.
5. Record the three-minute video and verify the final submission from a fresh clone.

The organisation pass intentionally stops before these product/solver changes. No score improvement or hackathon outcome is claimed from cleanup alone.
